# MiUbicacionAPP

Aplicación móvil desarrollada con Ionic + Angular + Capacitor.

## Características

- Obtención de ubicación GPS
- Apertura de ubicación en Google Maps
- Guardado en Firebase Firestore
- Guardado en Supabase
- Diseño responsive moderno
- APK Android

## Tecnologías utilizadas

- Ionic
- Angular
- Capacitor
- Firebase
- Supabase
- TypeScript

## Instalación

bash
npm install
ionic serve
